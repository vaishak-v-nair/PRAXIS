Questions before you start.

Will my project be uploaded?

The browser trial reads selected files in browser memory and makes no project upload. Local reviews keep a separate copy on your computer. GitHub intake, optional advisory checks, and connected model calls use the network when selected.

Do I need Docker or an API key?

No. The first source review needs neither. Docker or trusted host execution is optional for runtime checks; model keys are only needed for optional model review or AI-assisted planning.

Can PRAXIS say my app is production-ready?

It reports what its evidence supports. Source inspection is a first check, not proof of user-facing behavior or production operations. Deeper claims need relevant tests, observed journeys, and deployment evidence.

Will PRAXIS fix my code automatically?

No. It can prepare an agent brief or a fix plan. You review the handoff and separately authorize any edit or application of a proposed change.
