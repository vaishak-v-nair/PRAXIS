Before you start

Straight answers.
No mystery setup.

Do I need Docker?

No Docker is needed to start the local app or run the default source review. Deeper runtime checks are optional: explicitly authorize trusted local execution, or install Docker for container execution. Local checks retain this computer's file and network permissions and are not an OS sandbox.

What can the browser test prove?

It runs the existing source scanner on selected files in browser memory. Findings cite source conditions and need context. The browser test does not install project dependencies, run tests, observe user journeys, or declare a project production-ready.

Does my project leave my computer?

The browser test sends no project upload; it downloads its analysis runtime and engine. Local source inspection keeps its review copy on your computer. Optional model review sends bounded, redacted excerpts to configured providers. GitHub intake and advisory tools use the network. Local memory and offline signature checks have their own separate scope.

What do I need to install locally?

Node.js 22 or later. The managed launcher prepares a private Python runtime and locked app dependencies without a separate Git or Python installation. Initial setup needs downloads and can take several minutes. The setup page confirms the exact npm version before showing its public command; source-checkout instructions work while a release is pending.

Do I need an AI provider key?

Not for source inspection or the assembled agent brief. Local model review and fix planning are optional and require configured provider access. Those calls use a shared spending limit and may incur provider charges. A configured key is not evidence of remaining credit.

Will PRAXIS fix my project automatically?

The browser trial only provides findings and a copyable brief. Locally, you can draft a fix plan, review it, and choose a model handoff or your existing agent. Editing and applying changes require distinct authorization. A finished plan is not an implemented or verified fix.

Can builders, developers, and teams all use it?

Yes. They share the same workflow: understand source findings, see missing evidence, and decide the next action. The local app keeps project reviews and existing agent tools together. Portable briefs can be shared deliberately; the browser trial is not a hosted team workspace.

Are memory, receipts, and the mascot still included?

Yes. Existing CLI commands, hooks, supported receipt formats, MCP tools, and the Windows tray remain available. Open “Already using PRAXIS?” above for their guides. A valid receipt signature checks the record's integrity, not that every behavior is correct.
