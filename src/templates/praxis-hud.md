The HUD cannot run inside this chat — it is a live view that needs its own
terminal. Tell the user, short and friendly:

> Open a **second terminal** in this same folder and run: `praxis hud`
>
> It retells this session as a story — what you asked, what I said, what I
> actually did — one plain-English line each, with a live context-health bar.
> Press `q` to quit it. Nothing to configure, and it never touches this chat.

If they ask how it works: it reads the session transcript file Claude Code
already writes on disk — it never intercepts or overrides anything.
