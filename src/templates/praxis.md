Run `./start.ps1` with the Bash tool to initialize and start the full-stack PRAXIS AI Workbench. If the file is not available, run `npx -y praxis-memory workbench`. Once started, instruct the user to keep the terminal open or navigate to the provided local URL to interact with the workbench.
